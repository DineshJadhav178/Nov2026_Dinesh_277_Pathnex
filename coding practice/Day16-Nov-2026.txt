## 1. AWS KMS – Key Management Service

### Understand Encryption Fundamentals

Learn the following concepts:

- Symmetric encryption.
- Asymmetric encryption.
- Public and private keys.
- Encryption and decryption.
- HTTPS and TLS handshake.
- AWS Key Management Service (KMS).
- Customer managed keys.
- AWS managed keys.
- Key administrators.
- Key users.
- Key policies.
- Key rotation.

### Important Concepts

**Symmetric Encryption:**

Uses the same secret key for encryption and decryption.

**Asymmetric Encryption:**

Uses a public/private key pair for cryptographic operations.

**AWS KMS:**

Helps create and manage cryptographic keys used to protect data across AWS services.

### Practical Tasks

1. Open the AWS KMS console.
2. Explore existing AWS managed keys.
3. Create a customer managed symmetric encryption key.
4. Configure key administrators.
5. Configure key users.
6. Explore the key policy.
7. Understand key rotation options.
8. Explore how KMS integrates with S3 and other AWS services.
9. Understand key deletion scheduling and cancellation.

### AWS CLI Practice

```bash
# List KMS keys
aws kms list-keys

# Describe a KMS key
aws kms describe-key \
  --key-id <key-id>

# List aliases
aws kms list-aliases

# List key policies
aws kms list-key-policies \
  --key-id <key-id>

# Generate a data key
aws kms generate-data-key \
  --key-id <key-id> \
  --key-spec AES_256
```

### Practice Scenarios

1. What is the difference between symmetric and asymmetric encryption?
2. What is AWS KMS?
3. What is the difference between AWS managed keys and customer managed keys?
4. What is the purpose of a KMS key policy?
5. What is the difference between a key administrator and a key user?
6. How does S3 use KMS for encryption?

### Database Connectivity Commands

```bash
# Check connectivity to a database endpoint
nc -zv <database-endpoint> 3306

# PostgreSQL connectivity
nc -zv <database-endpoint> 5432

# Check DNS resolution
nslookup <database-endpoint>

# Check network connectivity
ping <database-endpoint>
```

Note: ICMP ping may be blocked even when the database port is accessible. Use the appropriate database client to verify actual connectivity.

### AWS Glue vs. Lambda

| AWS Glue | AWS Lambda |
|---|---|
| Designed for ETL and data integration | Designed for event-driven compute |
| Supports large-scale data processing | Suitable for short-running tasks |
| Supports Spark-based processing | Supports multiple managed runtimes |
| Suitable for complex data transformations | Maximum execution time of 15 minutes |
