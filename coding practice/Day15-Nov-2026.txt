### Practice AWS CLI Commands

```bash
# List Auto Scaling Groups
aws autoscaling describe-auto-scaling-groups

# List Launch Templates
aws ec2 describe-launch-templates

# Describe scaling policies
aws autoscaling describe-policies

# Check scaling activities
aws autoscaling describe-scaling-activities

# Update desired capacity
aws autoscaling set-desired-capacity \
  --auto-scaling-group-name my-asg \
  --desired-capacity 3

# Update minimum and maximum capacity
aws autoscaling update-auto-scaling-group \
  --auto-scaling-group-name my-asg \
  --min-size 1 \
  --max-size 5
```

### Practical Tasks

### Important IAM Concepts

**Trust Policy:** Defines which principal is allowed to assume an IAM role.

**Permissions Policy:** Defines which AWS actions the role can perform on specific resources.

**Least Privilege:** Grant only the permissions required for the application.

### Example WAF Rules

```text
Rule 1:
Block traffic from a specified IP address.

Rule 2:
Block traffic from selected countries.

Rule 3:
Apply rate-based protection when a client
exceeds the configured request threshold.

Rule 4:
Use managed rules to detect common
SQL injection and XSS attack patterns.
```

### Important Security Concepts

**SQL Injection:**
An attacker attempts to manipulate database queries through malicious input.

Prevention:
- Parameterized queries.
- Prepared statements.
- Input validation.

**Cross-Site Scripting (XSS):**
An attacker injects malicious scripts that execute in a user's browser.

Prevention:
- Output encoding.
- Input validation.
- Content Security Policy.
