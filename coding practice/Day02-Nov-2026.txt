# Day 02 – Linux Administration | Hands-on Practice

## 1. Filesystem and Disk Usage

Practice the following commands:

```bash
# Check filesystem disk usage
df -h

# Check inode usage
df -i

# Check directory size
du -sh /var/log

# Display directory sizes
du -h --max-depth=1 /var

# Find the 10 largest files under a directory
sudo find /var -type f -printf '%s %p\n' | sort -nr | head -10

# Check current directory size
du -sh .
```

**Practice tasks:**
- Identify directories consuming the most disk space.
- Find large log files.
- Compare disk usage and inode usage.
- Understand how inode exhaustion can prevent file creation even when disk space is available.

## 2. Hard Links and Symbolic Links

Create a test directory:

```bash
mkdir -p ~/day02-linux/links
cd ~/day02-linux/links
```

Create a file and a hard link:

```bash
echo "Linux Day 02 Practice" > original.txt

ln original.txt hardlink.txt

# Check inode numbers
ls -li
```

Create a symbolic link:

```bash
ln -s original.txt softlink.txt

# Check links
ls -li
```

**Deletion test:**

```bash
rm original.txt

# Check hard link content
cat hardlink.txt

# Check symbolic link
ls -l softlink.txt
cat softlink.txt
```

**Expected understanding:**
- Hard links refer to the same inode.
- Removing one hard-link name does not remove the data while another hard link exists.
- A symbolic link stores a path to its target and can become broken when the target is removed.

## 3. Linux Networking Commands

```bash
# Display network interfaces
ip addr

# Legacy interface command, if installed
ifconfig

# Test connectivity
ping -c 4 google.com

# Display listening TCP and UDP ports
sudo netstat -tulnp

# Modern alternative to netstat
ss -tulnp

# Check routes
ip route
```

**Practice tasks:**
- Identify your IP address.
- Check connectivity to an external host.
- List listening ports.
- Identify the process using a port.
- Compare `netstat` and `ss`.

## 4. wget vs curl

```bash
# Download a file using wget
wget https://example.com

# Download a file using curl
curl -O https://example.com/file.txt

# Display response headers
curl -I https://example.com

# Download with curl and follow redirects
curl -L -O https://example.com/file.txt
```

**Remember:**
- `wget` is commonly used for downloading files.
- `curl` is commonly used for transferring data and testing HTTP APIs.
- Both tools support downloading files.

## 5. Archive and Compression Using tar

Create a practice directory and files:

```bash
mkdir -p ~/day02-linux/archive
cd ~/day02-linux/archive

echo "Linux file 1" > file1.txt
echo "Linux file 2" > file2.txt
mkdir logs
echo "Sample log" > logs/app.log
```

Create a tar archive:

```bash
tar -cvf backup.tar file1.txt file2.txt logs/
```

Create a compressed archive:

```bash
tar -czvf backup.tar.gz file1.txt file2.txt logs/
```

List archive contents:

```bash
tar -tvf backup.tar
tar -tzvf backup.tar.gz
```

Extract the compressed archive:

```bash
mkdir extracted
tar -xzvf backup.tar.gz -C extracted/
```
