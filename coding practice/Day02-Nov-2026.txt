## 2. Linux Administration – Hands-on Practice

**Task 1: File and Directory Management**

- Create a directory named sre-practice.
- Create 5 text files inside it.
- Find all files with .log extension.
- Find files larger than 100 MB.
- Identify files modified within the last 24 hours.

**Task 2: Linux Permissions**

- Create a user named sreuser (if permitted).
- Change file ownership using chown.
- Configure file permissions using chmod.
- Understand 755, 644 and 700 permissions.
- Practice symbolic and numeric permissions.

**Task 3: Process and Resource Monitoring**

- Identify the top 5 CPU-consuming processes.
- Identify memory-consuming processes.
- Find the PID of a running service.
- Terminate a test process safely.
- Check disk and memory utilization.

Commands: ps, top, free, df, du, uptime, kill.

**Task 4: Linux Log Analysis**

- Search ERROR messages inside application logs.
- Count WARNING entries.
- Display the last 50 lines of a log file.
- Monitor logs continuously.
- Search logs for a particular timestamp.

Commands: grep, awk, sed, tail, head, journalctl.
