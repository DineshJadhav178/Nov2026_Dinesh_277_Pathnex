# Day 01 – Linux Command Practice

## Practical Exercises

### 1. Current Working Directory

```
pwd
```

### 2. List Files and Directories

```
ls
ls -l
ls -la
```

### 3. Create Directories

```
mkdir linux-practice
mkdir -p linux-practice/day01
```

### 4. Create Files

```
touch file1.txt file2.txt
```

### 5. Write Content into a File

```
echo "Learning Linux fundamentals" > file1.txt
cat file1.txt
```

### 6. Copy Files

```
cp file1.txt file2.txt
```

### 7. Rename Files

```
mv file2.txt backup.txt
```

### 8. Search for Files

```
find . -name "*.txt"
```

### 9. Check File Permissions

```
ls -l
```

### 10. Change File Permissions

```
chmod 755 file1.txt
chmod 644 backup.txt
```

### 11. Check Current User

```
whoami
id
groups
```

### 12. Check Linux System Information

```
uname -a
hostname
uptime
```
