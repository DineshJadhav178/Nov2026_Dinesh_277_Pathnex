# Day 02 – Linux Administration

## Topics Covered

### 1. Mindset and Career Development
- Importance of a positive and success-oriented mindset.
- Maintaining consistency in daily learning and practice.
- Improving English communication by watching English-language technical content.
- Staying focused on long-term IT career goals.
- Understanding the importance of continuous learning beyond routine support tasks.

### 2. Filesystem and Disk Usage
- Understanding Linux filesystem and disk usage.
- Identifying large files and directories using `du`.
- Understanding inodes and their role in storing file metadata.
- Checking inode availability and identifying inode exhaustion.
- Understanding the difference between disk space exhaustion and inode exhaustion.

### 3. Hard Links and Symbolic Links
- Understanding hard links and symbolic links.
- Creating hard links using `ln`.
- Creating symbolic links using `ln -s`.
- Understanding inode sharing between hard links.
- Understanding how file deletion affects hard links and symbolic links.
- Practical troubleshooting scenarios involving broken symbolic links.

### 4. Linux Networking Commands
- Understanding network interface information using `ifconfig`.
- Checking network connectivity using `ping`.
- Viewing network connections and listening ports using `netstat`.
- Understanding the difference between `wget` and `curl`.
- Basic network troubleshooting.

### 5. Archive and Compression
- Understanding file archiving and compression.
- Creating archives using `tar`.
- Extracting `.tar` and `.tar.gz` files.
- Understanding commonly used tar options.

### 6. Career and Interview Preparation
- Learning from real-world Linux administration scenarios.
- Explaining inode exhaustion and disk-space issues in interviews.
- Understanding the importance of practical troubleshooting experience.
- Communicating technical problems clearly and honestly.
