## 2. Security Groups vs Network ACLs

### Security Groups

Practice configuring:

- Inbound traffic rules.
- Outbound traffic rules.
- SSH access on port 22.
- HTTP access on port 80.
- HTTPS access on port 443.

### Network ACLs

Practice configuring:

- Allow and deny rules.
- Inbound and outbound rules.
- Rule priorities and numbering.
- Ephemeral ports for return traffic.

### Important Differences

| Security Groups | Network ACLs |
|---|---|
| Operate at instance/ENI level | Operate at subnet level |
| Stateful | Stateless |
| Support allow rules only | Support allow and deny rules |
| Return traffic is automatically allowed | Return traffic must be explicitly permitted |

**Practice scenarios:**

1. EC2 instance is not accessible through SSH. How would you troubleshoot it?
2. HTTP traffic is blocked. Which Security Group rules would you check?
3. What happens if a Security Group allows traffic but the NACL blocks it?
4. Why are ephemeral ports important in NACL configuration?

## 5. Amazon Route 53 – DNS Management

### Understand DNS Fundamentals

Learn the following record types:

- A Record – Maps a domain to an IPv4 address.
- AAAA Record – Maps a domain to an IPv6 address.
- CNAME Record – Maps one DNS name to another DNS name.
- NS Record – Identifies authoritative name servers.
- Alias Record – AWS-specific functionality that points supported records to AWS resources such as ALBs.

### Practical Tasks

1. Open Amazon Route 53.
2. Understand hosted zones.
3. Explore public hosted zones.
4. Understand private hosted zones.
5. Explore DNS record creation.
6. Understand A and CNAME records.
7. Explore Alias records pointing to an Application Load Balancer.
8. Understand DNS routing policies.

### DNS Troubleshooting Commands

```bash
# Check DNS resolution
nslookup google.com

# Query DNS records
dig google.com

# Check DNS using a specific record type
dig google.com A

# Check DNS response
dig google.com +short

# Check network connectivity
ping -c 4 google.com

# Check HTTP response
curl -I https://google.com
```

**Practice scenarios:**

1. Domain is not resolving. How would you troubleshoot it?
2. What is the difference between a public and private hosted zone?
3. What is the difference between an A record and a CNAME record?
4. How does Route 53 route traffic to an Application Load Balancer?
