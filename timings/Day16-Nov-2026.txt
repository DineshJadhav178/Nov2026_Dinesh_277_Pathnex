# Day 12 – AWS Advanced Services | KMS, Databases, ETL & CI/CD

## What I did today:

1. 1 hour – AWS Encryption and KMS: Symmetric and asymmetric encryption, HTTPS handshake fundamentals, AWS Key Management Service (KMS), key policies, key administrators and key users.
2. 1 hour – AWS Database Services: SQL vs. NoSQL databases, Amazon Aurora, DynamoDB, Redshift, database connectivity, endpoints and database security.
3. 1 hour – AWS Batch and ETL: Batch processing, compute environments, job queues, job definitions, AWS Glue, ETL workflows and Lambda runtime limitations.
4. 1 hour – Application Deployment and Content Delivery: Elastic Beanstalk, Platform-as-a-Service (PaaS), Amazon CloudFront, CDN, edge locations, caching and origin servers.
5. 1 hour – AWS Migration and Hybrid Connectivity: AWS Snowball, Data Transfer Terminal, AWS DataSync, AWS Direct Connect and on-premises to AWS connectivity.
6. 1 hour – AWS DevOps and Observability: CodePipeline, CodeBuild, CodeDeploy, rolling deployments, blue-green deployments, canary deployments and AWS X-Ray distributed tracing.
